# A finished set is made of real LEGO parts; 3D-printed bricks are an optional extra
- status: accepted
- by: Alec-42, 2026-11-15

Designs use real part numbers and only colours that exist for each part, and are written as LDraw files so
BrickLink Studio and other tools can render them, make instructions, and order parts. Real parts give a far
wider range of shapes (slopes, tiles, round parts) than printing our own bricks, which is what the
prototype did. The prototype's printable-brick generator is kept for a later optional output.
