# The app is one prompt bar, and the AI builds the model from parts
- status: accepted
- by: Alec-42, 2026-11-25

Alec: "the final app should be a single prompt bar, you can type or upload images (the 3d model
thing is actually not that important or required if AI is going to build it). The idea is that
AI builds it high quality." And: "words and picture - anything you want to throw in really. I
think that fits with it too as AI is building the thing."

So the home page is one bar: words, up to four pictures and a 3D model file, all of it reference
for the AI, and Build starts a free build (the guide on, about 200 parts, Fable 5.2 unless Opus
5.5 is chosen, under Options). The person's models are listed under it, free builds first. Turning
a 3D file into bricks with the solver stays, folded away as "the older way"; nothing of it was
removed. The agreement a paid AI run needs is a box under the bar, remembered in the browser,
beside a line that always says what Build sends, which Claude, how long and what it costs.

This is the app's side of the open proposal
`2026-11-19-the-ai-builds-with-real-parts-and-the-solver-becomes-a-tool.md`; it does not decide
that proposal for the engine. `2026-11-15-a-3d-model-is-always-the-starting-point.md` still holds
for the solver's pipeline, the older way; in a free build a 3D file is one more reference.
