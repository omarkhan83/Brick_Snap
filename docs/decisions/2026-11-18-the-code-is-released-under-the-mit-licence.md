# The code is released under the MIT licence
- status: proposed
- by: Alec-42, 2026-11-18

The repository is public but has no licence, so today nobody, teammates included, has permission to reuse
any of it. MIT is the shortest common licence: anyone may use, change and share the code if they keep the
copyright notice. It is what three.js and trimesh, the two libraries we lean on most, use, so nothing we
ship conflicts with it. It covers our code only: the parts data stays under the LDraw library's CC BY
terms and each sample model under its own licence, credited as they are now. Omar wrote the prototype in
`legacy/`, so this needs his agreement as well as the lead's.

Rejected: GPL (anyone who shares a changed version must share their changes too, which is fairer in one
way but would make it harder to put BrickSnap inside something else later); Apache 2.0 (like MIT with a
patent clause and much more text; we have no patents to grant); no licence (the current state, which
stops even the team from reusing its own work elsewhere).
