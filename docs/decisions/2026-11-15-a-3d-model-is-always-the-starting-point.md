# A 3D model is always the starting point; how it was made is not the core's concern
- status: superseded for the main line by 2026-11-19-the-ai-builds-with-real-parts-and-the-solver-becomes-a-tool.md (still true of the older 3D-to-bricks way)
- by: Alec-42, 2026-11-15

The core takes a 3D model (the "seed") and nothing else. Photos, phone scans, AI image-to-3D, CAD, and the
prototype's three-photo mode are separate "seed makers" that produce a model. This keeps one pipeline to
get right, and lets any future input method plug in without touching it.
