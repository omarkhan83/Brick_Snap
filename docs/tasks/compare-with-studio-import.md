# The same models through BrickLink Studio's own converter, pictured next to ours
- status: open
- owner: nobody
- stage: 4

BrickLink Studio can turn a 3D model into stacked bricks by itself ("Import 3D model as sculpture"). That
is what BrickSnap has to beat, and the walkthrough should show the two side by side. This needs a person
with Studio (Windows or Mac), because the import is only in Studio's menus.

For each of the cat, the duck and the car (`samples/models/`): import it in Studio at 16 studs along its
longest side with Studio's default settings, and export the result as an LDraw file (`cat-studio.ldr`,
and so on). Done when the three files are in hand, each is pictured next to our build of the same model
at the same size (LeoCAD draws any LDraw file: see the Studio task's notes), the part counts are written
down, and the cat's picture is in `docs/WALKTHROUGH.md`.
